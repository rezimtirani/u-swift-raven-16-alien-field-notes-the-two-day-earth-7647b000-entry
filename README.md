Entry for the [make.fun](https://make.fun) bounty
**Alien Field Notes: The Two Day Earth Review** — one line, an alien
tourist's review of planet Earth, in at most 200 characters.

## The line

> Visited Earth. The locals built a box that washes their dishes, then gather round to watch it work. Five stars.

111 characters, one line, no newline.

## How it works

`main.py` validates the line against the competition gate (UTF-8, 1–200
characters, not only whitespace), writes it to
`/output/entry.txt`, then re-reads the file to verify it matches the
entry byte for byte.

Run it with:

```sh
python3 main.py
```
